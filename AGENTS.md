# Контекст проекта

## Запрос пользователя
- Подготовить Node.js-проект для тестового задания AI Fullstack Developer.
- Создать окружение, документацию и публичный GitHub-репозиторий.

- Пользователь пишет основной скрипт сам; отдельно разрешил ИИ добавить обработку ошибок.
- Новый запрос: сохранить исходную версию, добавить ошибки в отдельной ветке, запушить и смержить.

## Требования задания
- CLI принимает HTTP(S)-URL и делает 10 последовательных запросов.
- Каждый ответ нужно прочитать полностью до следующего запроса.
- Вывести среднее время, общий объём и скорость в Мбит/с.
- Формула скорости и команды запуска описаны в README.md.

## Подготовлено ИИ
- Node.js 24.x, ES-модули, package.json и package-lock.json без внешних зависимостей.
- Команды npm start и npm run check; последняя проверяет только синтаксис.
- .nvmrc, .editorconfig, .gitignore; код находится в src/index.js (JavaScript).
- README с требованиями, запуском, единицами, ограничениями и списком проверок.
- Встроенные API Node.js сверены с документацией через Context7.
- GitHub: https://github.com/dar4x/download-speed-cli, основная ветка main.

## Инструкции следующим агентам
- Эти инструкции относятся ко всему репозиторию.
- Не реализовывать скрипт за пользователя без его нового прямого запроса.
- Разрешение на обработку ошибок не распространяется на цикл и расчёт скорости.
- Можно помогать с объяснениями, документацией и ревью присланного кода.
- Не добавлять зависимости, фреймворки и инфраструктуру без необходимости.
- Не называть успешную проверку синтаксиса проверкой работоспособности.
- После содержательных изменений обновлять этот контекст и README при необходимости.
- Пушить готовые проверенные изменения обычными коммитами, без force push.
- Для вопросов об API Node.js и библиотек сначала обращаться к Context7.
- Не сохранять токены, приватные URL и другие секреты в репозитории.
