# Download Speed CLI

Тестовое задание на позицию AI Fullstack Developer: консольный скрипт на Node.js
для измерения скорости скачивания с указанного адреса.

**Статус:** реализован один запрос с полным чтением ответа и обработкой ошибок.
Скрипт выводит количество прочитанных байтов. Цикл из 10 запросов, измерение
времени и расчёт скорости пока не реализованы — их автор добавит самостоятельно.

## Требования задания

- Принять URL из командной строки.
- Выполнить ровно 10 последовательных HTTP(S)-запросов к этому URL.
- Полностью прочитать каждый ответ перед следующим запросом.
- Рассчитать среднее время запроса и общий объём скачанных данных.
- Вывести скорость скачивания с указанием единиц измерения.

## Окружение и запуск

Нужен Node.js 24.x и входящий в его комплект npm. Внешних npm-зависимостей нет:
достаточно встроенных возможностей Node.js. Проект использует ES-модули.

```bash
git clone https://github.com/dar4x/download-speed-cli.git
cd download-speed-cli
# Если используешь nvm:
nvm install
nvm use
npm ci
npm run check
```

`npm ci` проверяет установку по lock-файлу; дополнительных пакетов не скачивает.
`npm run check` проверяет только синтаксис и не подтверждает выполнение задания.
Если nvm не установлен, достаточно самостоятельно установить Node.js 24.x.

Запуск одного запроса:

```bash
npm start -- "https://example.com/large-file.bin"
```

Адрес выше — пример синтаксиса; для замера нужен реальный доступный файл.
Прямой запуск: `node src/index.js "https://example.com/large-file.bin"`.

Пример результата проверки на локальном сервере, вернувшем 456 байт двумя частями:

```text
bytes length: 456
```

## Обработка ошибок и проверки

Принимается ровно один непустой HTTP(S)-URL без логина и пароля.
При ошибке сообщение выводится в stderr, код завершения — 1; при отмене через
Ctrl+C — 130. Неуспешная загрузка не выводит количество байтов.
Таймаут 30 секунд действует на запрос вместе с полным чтением ответа.
HTTP-ошибки выводятся с кодом статуса; их тела не скачиваются полностью.

```bash
npm test
```

Тесты используют встроенный `node:test`, локальный HTTP-сервер и моделирование
сетевых ошибок; внешние сервисы и npm-пакеты для них не нужны.
Список ошибок, устройство обработки и история изменений — в
[docs/ERROR_HANDLING.md](docs/ERROR_HANDLING.md).

## Единицы и расчёты

Эти расчёты относятся к следующему этапу и пока не выполняются скриптом.

- Время: секунды.
- Общий объём: байты тел ответов, прочитанные программой.
- Скорость: Мбит/с, где 1 Мбит = 1 000 000 бит, 1 байт = 8 бит.

```text
среднее время = сумма длительностей 10 запросов / 10
скорость, Мбит/с = общий объём в байтах × 8 / суммарное время в секундах / 1 000 000
```

Каждый интервал начинается перед отправкой запроса и заканчивается после полного
чтения тела ответа. Скорость рассчитывается через общие объём и время.
HTTP-заголовки и служебный сетевой трафик в объём не входят. При использовании
`fetch` нужно учитывать, что сжатое тело может автоматически распаковываться.
Результат характеризует скачивание с выбранного сервера, а не предельную
пропускную способность интернет-канала.
